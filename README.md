## 👨‍💻 About Me

I'm a Test & Validation Engineer with more than 5 years of professional experience in software development, system validation, and test automation.

Throughout my career, I've worked on different types of software and embedded systems, from automotive electronic control units (ECUs) and safety-critical embedded software to web-based applications and energy monitoring systems.

My experience covers several stages of the software development lifecycle, including requirements analysis, test strategy definition, test design, software implementation, integration, verification, validation, and defect management.

In the automotive domain, I have been involved in embedded software development and validation activities, working with technologies such as Embedded C, AUTOSAR, CAN communication, UDS diagnostics, and MATLAB/Simulink. I have also performed SIL and HIL testing to verify software behavior and ensure system reliability.

On the testing side, I have designed and executed functional, integration, regression, and system-level test campaigns. I have developed automated testing solutions using Python, CAPL, Robot Framework, and Selenium, helping improve test coverage and reduce execution time.

I also have experience coordinating testing activities, following up on defects, reporting progress, supporting continuous improvement, and sharing technical knowledge through training and mentoring.

I'm particularly interested in embedded software, automotive systems, software quality, test automation, and AI-assisted software engineering.

**My goal is to build reliable software, improve testing processes, and contribute to the delivery of high-quality systems.**
